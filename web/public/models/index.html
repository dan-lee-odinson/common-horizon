Lunar hardware models

Simple, true-to-size shapes of lunar hardware, built with code for the Common Horizon site (NASA Space Apps 2026, Lunar Landing Site Navigator). Units are meters, Y is up, and each model's origin is the centre of its footprint on the ground. Every model is an illustrative shape, built with SI/AI-written code; its sizes and their sources are listed below, read from the JSON file next to each model.
